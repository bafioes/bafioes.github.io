# Analisi 3

Il corso di analisi 3 è un introduzione all'analisi funzionale. I suoi contenuti trattano gli spazi di Banach, con particolare interesse agli spazi $L^p$, gli operatori lineari (tra cui la trasformata di Fourier), gli spazi di Hilbert (lo spazio $L^2$ è lo spazio naturale delle serie di Fourier) e infine si studiano dei teoremi molto importanti e delle nozioni utili ai corsi di analisi della magistrale.
