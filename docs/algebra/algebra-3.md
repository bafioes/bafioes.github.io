# Algebra 3 [A]

Il corso di algebra 3 tratta la teoria di Galois, iniziando sviluppando la teoria delle estensioni di campi fino a dimostrare il teorema fondamentale della teoria di Galois (finita). Fatto ciò, si trattano diverse applicazioni di tale teoria, degna di nota la costruzione del percorso verso il teorema di Abel-Ruffini.
