# Calcolo Numerico [C]

Il corso di calcolo numerico è un'introduzione all'analisi numerica. I suoi contenuti vertono sui metodi per trattare matrici e funzioni reali di variabile reale. In particolare, si trattano sistemi lineari (Gauss e metodi iterativi), decomposizioni di matrici (tra cui Cholesky e QR), formule di quadratura per integrali, ricerca di autovalori e interpolazione.

Sebbene il file sia categorizzato nel gruppo [C], bisogna notare che le note sono state fedelmente trascritte da un file word (primo file da me redatto al computer!), dunque la loro affidabilità è alta.
